
# Budget Goat

**By Madilyn P. Jarman**


## About the Project

This project was ompleted in partial fulfilment of the requirements for the Jan. 2026 Code: You Web Development Pathway.

I chose this topic because of a personal interest in financial literacy and wanted to make it easier for people to understand how to get more control over their personal finances to more easily acchieve their financial goals.

The budget worksheet content and layout was adapted from the Aug. 2024 version of the Budget Worksheet produced by the U.S. Federal Trade Commission. The origional version is available at consumer.gov. It is part of a wider collection of free resources to improve basic financial literacy.

## Getting Started

- Clone the project from GitHub
- Open in VS Code
- Go live!!! (For best results, please use Google Chrome)
- Fill out the worksheet by entering values for each relevant line item based on your personal spending patterns (or just some positive numbers that you like)
- The worksheet will total the line items within each subcategory and give you an idea of how you are doing staying within your budget

## Features

**Feature Implementation**
- Integrate an API
The colors in the chart are generated randomly using the [colors API](https://www.thecolorapi.com/)
- At least 1 media query for site responsiveness
The project contains a media query.
- Validate user input and either prevent the invalid input or inform the user about it (in all cases prevent invalid input from being stored or saved).
The form notifies the user if they enter a negative number and displays an error message instructing them to make corrections.
- Create a function that accepts two or more input parameters and returns a value that is calculated or determined by the inputs.  Basic math functions don’t count (e.g. addition, etc).
The project uses a function to check if the user inputs are positive integers so they can be totaled.
- Visualize data in a user friendly way. (e.g. graph, chart, etc) This can include using libraries like ChartJS
The project incorporates a chart to provide a visual example to help users visualize their relative spending by expense category. Additionally, the overall layout of the form follows the basic format of a financial balance sheet to make it easier for people to mentally group expenses and distingush between income and expenses.
- Analyze data that is stored in arrays, objects, sets or maps and display information about it in your app.
The input data is stored in objects and evaluated to provide a message to the user about whether or not their expenses are within their income. This calculation determines the nature of the relationship between the different portions of a users budget.
